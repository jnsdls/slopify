# Code of conduct

Be decent to each other. Argue about code, not about people. No harassment, no slurs, no publishing anyone's private information, no sustained hostility after being asked to stop.

The maintainer may edit, hide, or delete comments, and may block anyone who ignores this, without a warning first for the clear cases.

If someone is behaving badly towards you in this project, message [@jnsdls](https://github.com/jnsdls) on GitHub.
