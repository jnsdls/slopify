# Prototype: dropdown variants

Throwaway. Answers [issue #9](https://github.com/jnsdls/slopify/issues/9): what goes in the menu-bar dropdown and how it's laid out.

```sh
open prototype/dropdown/index.html
```

Three layouts, switch with the yellow bar at the bottom, the arrow keys, or `?variant=A|B|C`. Play/pause and source rows are clickable so the states can be seen. Nothing talks to Spotify.
